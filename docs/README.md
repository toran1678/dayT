# DayT Docs (`docs/`)

프로젝트 기획서, 시스템 아키텍처, 데이터베이스 설계(ERD), 화면 설계서 및 서비스 간 API 명세를 관리하는 폴더입니다.

## 포함 내용
- **기획 및 화면 설계**: 기능 정의서, 유저 플로우, 와이어프레임
- **ERD (Database Modeling)**: `User`, `Couple`, `Place`, `Course`, `Course_Place_Mapping`, `Pet`, `Diary` 등 스키마 문서
- **API 명세 (Contracts)**:
  - Mobile/Web ↔ Spring Boot (`backend`) REST / WebSocket API 명세
  - Spring Boot ↔ FastAPI (`ai-service`) 내부 통신 JSON 스키마
